spark_data_analysis.datasets.clusterdata_2011_2 module¶

Clusterdata 2011-2 dataset.

This module contains the schema definitions for the Clusterdata 2011-2 dataset from Google. This module also provides functions to load the dataset into a DataFrame using Spark. The functions are cached to avoid loading the same data multiple times and provide a way to specify the number of parts to load.

spark_data_analysis.datasets.clusterdata_2011_2.format_parts_file_regex(parts: int | Literal['full']) → str¶

Format the number of parts to load into a file regex.

Example

>>> format_parts_file_regex(5)
"{part-00000*,part-00001*,part-00002*,part-00003*,part-00004*}"
Parameters:

parts (int | Literal[&quot;full&quot;]) – Number of parts to load. If &quot;full&quot;, load all parts.

Raises:

ValueError – If the number of parts is greater than the maximum number of parts.

Returns:

The formatted file regex.

Return type:

str
