spark_data_analysis.rich module¶

spark_data_analysis.rich.table(console: Console, title: str, dictionary: dict[str, list | Any], render: bool = True) → Table¶

Create a table from a dictionary.

Uses the rich library to create a table from a dictionary where the keys are the column names and the values are the rows.

Parameters:

  • console (Console) – rich console

  • title (str) – Title of the table

  • dictionary (dict[str, list | Any]) – Dictionary with column names as keys and lists as values

  • render (bool, optional) – Wether to print the console to terminal or not. Defaults to True.

Returns:

rich table object with the data from the dictionary

Return type:

Table
