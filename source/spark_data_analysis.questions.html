Module contents¶

Questions module for spark_data_analysis package.

This module contains the questions proposed from the assignment of the course “Large Scale Data Analysis and Distributed Systems” from the University of Grenoble Alpes plus the two additional questions proposed by the author of this package. Each question is identified by a unique number in the format qX, where X is the question number.
